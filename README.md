# DevOps Git Workflow Challenge

## Project Overview

This repository demonstrates essential Git and GitHub operations used in a basic DevOps workflow. It includes a sample deployment script and documents the use of branches, commits, stashing, and merge conflict resolution.

## Project Files

- `deploy.sh` — A Bash script representing a simple application deployment process.
- `README.md` — Project overview and usage information.
- `PROOF_OF_WORK.md` — Commit history and answers to the lab reflection questions.

## Branch Structure

- `main` — Contains the primary version of the project.
- `development` — Used to make and test development changes.
- `staging` — Used to represent changes prepared for staging.

## Running the Script

Give the script execution permission if necessary:

```bash
chmod +x deploy.sh
```

Execute it using:

```bash
./deploy.sh
```

## Purpose

The repository is intended for educational practice with Git commands, branch management, temporary change storage, merge conflict handling, and GitHub Pull Requests.
